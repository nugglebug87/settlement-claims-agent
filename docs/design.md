# Rose-led gothic editorial design

The interface follows the owner's direction: deep shadows, candlelight, dramatic contrast, burgundy velvet, black lace, distressed texture, antique gold, ornate frames, abundant dark roses, and a discreet leopard-print detail in the photographic still life.

Gold roses recur in the navigation mark, empty states, summary cards, dialog headers and corner ornaments. Tables keep quiet surfaces and readable type. Cormorant Garamond supplies editorial headings, Allura supplies handwritten accents, and system sans serif supplies clear controls and labels.
